## Git Commit Rules

When creating git commits, always follow these rules:
- Format the message using Conventional Commits: `<type>(<scope>): <description>`
- Allowed types: `feat`, `fix`, `docs`, `style`, `perf`, `refactor`, `test`, `build`, `chore`, `ci`
- The description must be in lowercase and imperative mood (e.g., "add auth layout" not "Added auth layout")
- Wrap the body lines at 72 characters if a detailed explanation is needed
